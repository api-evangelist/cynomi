# Cynomi

> Cynomi is an AI-powered, automated virtual CISO (vCISO) platform built for MSPs, MSSPs, and consultancies to deliver scalable cybersecurity and compliance services. It automates risk assessments, generates tailored security policies and remediation plans, maps controls to frameworks (NIST, ISO 27001, SOC 2, PCI DSS, GDPR, NIS2, HIPAA), and tracks posture over time. Cynomi exposes a Public API for bi-directional task synchronization with PSA and ticketing systems, plus pre-built integrations with vulnerability scanners and cloud security tools.

## Platform
- [Cynomi vCISO Platform](https://cynomi.com/vciso-platform/): AI-driven vCISO platform overview.
- [Integrations](https://cynomi.com/platform/integrations/): Pre-built scanner, cloud, and PSA integrations.
- [Public API](https://cynomi.com/platform/integrations/public-api/): Platform-agnostic REST API for bi-directional PSA / ticketing task synchronization (push remediation tasks, pull status updates).
- [Assessments](https://cynomi.com/platform/assessments/): Automated security and compliance assessments.
- [Frameworks](https://cynomi.com/frameworks/): Supported compliance frameworks library.
